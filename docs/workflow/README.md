# Tony News Project Workflow

Start every non-trivial session with this chain:

1. `/Skills/project-session-bootstrap/SKILL.md` in File Library.
2. [`AGENTS.md`](../../AGENTS.md) in this repository.
3. Search File Library for the exact filename `Tony-News-SKILL_INDEX-v1.1.1.md`.
4. [`plan-and-task-first.md`](./plan-and-task-first.md).
5. The active GitHub issue, linked plans, ADRs, benchmark manifests, design decisions, pull requests, and exact-revision evidence.

File Library is treated as a flat searchable catalog. Do not use generic `SKILL_INDEX.md` or conceptual `/Tony News/...` paths as the locator because they can collide or fail to surface. `AGENTS.md` records the exact verified project skill filenames. The older `Tony-News-SKILL_INDEX.md` and `Tony-News-SKILL_INDEX-v1.1.0.md` files are historical only.

The mandatory execution rule is documented in [`plan-and-task-first.md`](./plan-and-task-first.md). The compact continuity checklist is in [`SESSION_CONTINUITY.md`](./SESSION_CONTINUITY.md), and the project-wide tracking invariant is in [`TRACKING.md`](./TRACKING.md).

Repository state and GitHub issues are authoritative for project status. File Library is authoritative for skill contracts. Chat history and assistant memory are supplemental only.
