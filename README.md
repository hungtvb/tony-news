# Tony News

AI-assisted, event-centric news aggregation for Technology, Entertainment, and Sports.

> Status: Phase 0 technical spike.

The project prioritizes source attribution, conservative story clustering, citation-backed summaries, and graceful degradation when AI is unavailable.

## Documentation

Product and architecture documentation is maintained in Notion. Repository-local ADRs, benchmark manifests, setup instructions, and runbooks will be versioned alongside implementation.
